# GlowRide landing page — Lunea-inspired rebuild

Static landing page. No Shopify, no backend, no payment gateway.

## Files
- `index.html` — landing page
- `assets/cabin-after.jpg` — demo after/glow image
- `assets/cabin-before.jpg` — demo before image

## To replace demo visuals
Replace these files with real images using the same filenames:
- `assets/cabin-after.jpg`
- `assets/cabin-before.jpg`
